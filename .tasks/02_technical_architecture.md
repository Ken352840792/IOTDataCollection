# 技术架构设计

## 🏗️ 整体架构概述

IoT工业数据采集平台采用现代化的分体式架构，结合DDD领域驱动设计和Clean Architecture原则，构建高性能、高可用、易扩展的工业IoT系统。

## 📊 架构层次设计

### 1. 表现层 (Presentation Layer)
**职责**：用户交互和数据展示
- **Web管理界面**：Vue 3.0 + Element Plus，提供设备管理、监控仪表板、调试控制台
- **实时监控界面**：独立的监控模块，支持多种视图模式
- **移动端界面**：响应式设计，支持移动设备访问
- **API接口**：RESTful API + GraphQL，支持第三方系统集成

### 2. 应用服务层 (Application Service Layer)
**职责**：业务用例编排和跨领域协调
- **设备管理服务**：设备注册、配置管理、状态监控
- **数据采集服务**：采集任务管理、数据质量控制
- **系统监控服务**：资源监控、告警处理、性能分析
- **实时查询服务**：数据流查询、历史数据分析
- **调试服务**：设备测试、数据库查询、协议诊断
- **协议管理服务**：协议上传、版本管理、分发控制、兼容性测试
- **权限管理服务**：用户认证、角色授权、数据权限

### 3. 领域层 (Domain Layer)
**职责**：核心业务逻辑和规则
- **8个核心领域**：组织管理、设备管理、数据采集、系统监控、实时查询、设备调试、规则引擎、身份权限
- **聚合根管理**：业务实体的生命周期管理
- **领域事件**：跨领域的业务事件通信
- **业务规则引擎**：JavaScript脚本执行和热更新

### 4. 基础设施层 (Infrastructure Layer)
**职责**：技术能力支撑
- **数据持久化**：MySQL配置数据、InfluxDB时序数据、SQLite本地缓存
- **消息通信**：NanoMQ MQTT消息队列
- **缓存服务**：Redis分布式缓存
- **协议通信**：HslCommunication工业协议栈
- **日志服务**：结构化日志记录和分析

## 🚀 技术栈选型

### 后端技术栈
- **开发框架**：.NET 8（不使用顶级语句）
- **架构模式**：DDD + Clean Architecture + CQRS
- **数据访问**：Entity Framework Core + 仓储模式
- **API框架**：ASP.NET Core Web API
- **实时通信**：SignalR
- **身份认证**：JWT + ASP.NET Core Identity
- **规则引擎**：Jint JavaScript引擎
- **单元测试**：xUnit + Moq

### 前端技术栈
- **前端框架**：Vue 3.0 + Composition API
- **UI组件库**：Element Plus
- **状态管理**：Pinia
- **图表库**：ECharts
- **HTTP客户端**：Axios
- **构建工具**：Vite
- **TypeScript**：强类型支持

### 数据存储技术
- **关系数据库**：MySQL 8.0+（配置数据、用户权限、组织架构）
- **时序数据库**：InfluxDB（实时数据、监控指标、历史记录）
- **本地数据库**：SQLite（采集端本地缓存、断网保障）
- **缓存数据库**：Redis（高频访问数据、会话缓存）

### 消息中间件
- **MQTT Broker**：NanoMQ（轻量级、高性能、多线程异步）
- **消息协议**：MQTT 3.1.1/5.0（支持QoS、保留消息、遗嘱消息）
- **客户端库**：MQTTnet（.NET MQTT客户端）

### 工业协议支持
- **主要协议库**：HslCommunication
- **支持协议**：Modbus TCP/RTU、OPC-UA、Siemens S7、Mitsubishi等
- **扩展机制**：协议插件化，支持自定义协议适配器

## 🔄 分体式架构设计

### 采集端架构
**部署模式**：一设备一采集端，独立部署
**核心功能**：
- **数据采集引擎**：多协议支持，并发采集
- **规则执行引擎**：JavaScript脚本边缘计算
- **本地数据缓存**：SQLite断网续传保障
- **系统资源监控**：CPU、内存、磁盘、网络监控
- **MQTT通信客户端**：与处理端双向通信
- **配置热更新**：远程配置下发和应用

### 数据处理端架构
**部署模式**：集中式部署，处理所有设备数据
**核心功能**：
- **NanoMQ消息代理**：高性能消息路由和分发
- **数据存储引擎**：MySQL配置存储 + InfluxDB时序存储
- **Web API服务**：RESTful接口和GraphQL查询
- **实时通信服务**：SignalR推送和双向通信
- **权限认证服务**：JWT认证和RBAC授权
- **监控告警服务**：系统监控和告警处理

## 📡 通信架构设计

### MQTT主题架构
**层次化主题设计**：
- **数据上报**：`data/{enterprise}/{site}/{area}/{device_code}/{data_type}`
- **设备配置**：`config/{device_code}`
- **控制指令**：`control/{device_code}`
- **设备状态**：`status/{device_code}`
- **系统监控**：`monitoring/{device_code}/system/{metric_type}`
- **调试操作**：`debug/{device_code}/{operation_type}`
- **协议分发**：`protocol/download/{device_code}` 和 `protocol/download/broadcast`
- **协议状态**：`protocol/status/{device_code}`
- **告警消息**：`alert/{enterprise}/{site}/{area}/{device_code}`

### 消息QoS策略
- **实时数据**：QoS 0（最多一次）- 追求性能
- **配置数据**：QoS 1（至少一次）- 保证送达
- **控制指令**：QoS 2（恰好一次）- 确保可靠
- **告警消息**：QoS 1（至少一次）- 保证送达

## 🔐 安全架构设计

### 身份认证机制
- **用户认证**：基于JWT的无状态认证
- **设备认证**：基于证书或密钥的设备身份验证
- **API安全**：OAuth 2.0 + OpenID Connect
- **会话管理**：Redis分布式会话存储

### 权限控制体系
- **RBAC模型**：用户-角色-权限三级管理
- **数据权限**：基于组织架构的数据访问控制
- **API权限**：接口级别的权限验证
- **功能权限**：页面和操作级别的权限控制

### 数据安全保护
- **传输加密**：TLS/SSL加密传输
- **数据加密**：敏感数据AES加密存储
- **SQL注入防护**：参数化查询和输入验证
- **XSS防护**：输出编码和CSP策略

## ⚡ 性能架构设计

- **异步处理**：大量使用async/await异步编程

### 可扩展设计

- **负载均衡**：API网关和负载均衡器

### 监控和诊断
- **应用性能监控**：APM工具集成
- **健康检查**：服务健康状态监控
- **链路跟踪**：分布式请求链路追踪
